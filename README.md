## 🌟 Overview

**SkilledHyre Labs** helps businesses transform ideas and complex technical challenges into scalable digital products, intelligent AI automation systems, and measurable growth.

This portfolio web application features a dark-themed glassmorphism aesthetic with fluid micro-interactions, canvas node animations, interactive case study showcases, client rating systems, and a multi-step project discovery wizard.

---

## ✨ Key Features & Sections

- **⚡ Interactive Hero Ecosystem**: Dynamic canvas particle/node network background illustrating connected capabilities.
- **🏢 Company in One Glance**: Interactive tabbed navigation highlighting key operational pillars.
- **💼 Capabilities & Tech Constellation**: Showcase of technology stack expertise (Next.js, C# .NET, AI & ML, Cloud Infrastructure, DevOps, Mobile Apps).
- **🎬 Cinematic Work Showcase**: Dynamic case studies grid complete with impact metrics and filter categories.
- **📈 How We Work & Why Us**: Process timeline breakdown from discovery to scale, alongside core client value drivers.
- **👥 Team Showcase & Modals**: Detailed team profile modals detailing expertise, tech focus, and contributions.
- **⭐ Client Proof & Testimonials**: Dynamic review filters, rating breakdowns, verified badges, and an interactive review submission form.
- **🧙‍♂️ Project Starter Wizard**: Interactive multi-step modal form for client project discovery and scope estimation.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router)

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js 18.x or later installed on your system.

### 1. Clone the Repository

```bash
git clone https://github.com/priyayayayayaaa/skilledhyre_portfolio.git
cd skilledhyre_portfolio
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 4. Build for Production

```bash
npm run build
npm run start
```
